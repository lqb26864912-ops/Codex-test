# 每日新闻视频：自动任务操作手册

每天早上（曼谷时间）定时任务会按这份手册做一条新闻视频。手册是给执行任务的 Claude 看的。

## 目标

找出过去 24–48 小时里，和**泰国签证、入境、移民局、在泰华人生活安全**相关、最值得做的一条新闻，做成一条 20–35 秒的竖屏新闻卡片视频，附上发布文案。最后把成片发给用户。

## 步骤

1. **找新闻**：用 WebSearch 搜中文、泰文、英文新闻（泰国移民局、中国驻泰国大使馆、泰国外交部、泰叻报、Bangkok Post、The Thaiger、Khaosod 等）。只选**发布时间在 48 小时内**的新闻。
2. **核实**：至少两个独立来源，或一个官方来源。数字要和原文一致，分清"流水"和"金额"、"嫌疑人"和"罪犯"、"传闻"和"官方"。核实不了的新闻不做。
3. **选题标准**：和用户业务相关（签证、入境、续签、90 天报到、长住、在泰华人的风险提醒）；对观众有用；能自然引到"在泰国的事，先问清楚再做 / 有问题，私信我们"。
4. **做视频**：复制 `tools/video/exchange_news.html` 或 `refused_news.html` 作为模板，换成当天的内容（钩子 → 新闻卡片 ①② → 给观众的提醒 → 结尾）。文件名用英文，比如 `daily_YYYYMMDD.html`。
5. **准备环境**（每次都要做）：
   - 字体：在 `tools/video/` 下执行 `npm pack @fontsource/noto-sans-sc@5.1.1 && tar xzf fontsource-noto-sans-sc-5.1.1.tgz && mv package fonts/package`（先 `mkdir -p fonts`），然后删掉 tgz。
   - Playwright 和 ffmpeg 环境里已经有，不要重装 Playwright。
6. **渲染**：`node render.js preview daily_YYYYMMDD.html 2,8,14,20` 先看关键帧，检查文字没有被挡、没有单字掉行、内容在 x 70–900、y 220–1560 范围内；然后 `node render.js full daily_YYYYMMDD.html`，再用 README 里的 ffmpeg 命令编码。
7. **抽帧检查**成片，再交付。
8. **交付**：用 SendUserFile 发给用户，`status: "proactive"`：
   - 视频 MP4
   - 发布文案 TXT：标题、正文、话题标签、置顶评论、**来源链接**、发布注意事项
9. **提交模板**：只把 `daily_YYYYMMDD.html` 提交到当前分支并推送。不要提交字体、帧图片和 MP4。
10. **没有合适的新闻**时，不硬做。改为发一句话给用户说明今天没有值得做的新闻，并推荐一个常青选题（材料清单、续签提醒等）。

## 必须遵守

- 不写：包过、保证出签、保证入境、保关、特殊渠道、内部关系、百分之百。
- 不用别人的新闻视频或图片画面，全部用自己的卡片设计。
- 不放人脸、嫌疑人姓名、证件号码。
- 抖音文案里不留微信、WhatsApp、电话、网址。
- 案件类新闻要写"案件以司法机关最终认定为准"；政策类写"以官方最新公布为准"。
- 不确定的说法不写进视频，写进文案的"需要用户确认"部分。
- 回复用户用简体中文。
